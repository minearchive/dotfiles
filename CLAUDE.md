# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A NixOS + Home Manager dotfiles repository managing multiple hosts and user profiles with Nix Flakes. Wayland-first desktop environment built around Hyprland, QuickShell (QML), and Material Design 3 theming via Matugen.

## Applying Configurations

**System (NixOS):**
```bash
sudo nixos-rebuild switch --flake .#msiLaptop   # Intel laptop
sudo nixos-rebuild switch --flake .#desktop     # NVIDIA desktop
sudo nixos-rebuild switch --flake .#wsl         # WSL
```

**Home Manager:**
```bash
home-manager switch --flake .#pastel@msiLaptop   # Active profile, Intel laptop
home-manager switch --flake .#pastel@desktop    # Active profile, NVIDIA desktop
home-manager switch --flake .#material          # Deprecated reference profile
home-manager switch --flake .#wsl               # WSL minimal profile
```

There is no bare `pastel` attribute — the profile is split per host (`pastel/pastel.nix` + `pastel/hosts/<host>.nix`).

**Convenience scripts (generated by `init.sh`, git-ignored):**
```bash
./rebuild.sh       # sudo nixos-rebuild switch --flake .#<selected host>
./update-home.sh   # home-manager switch --flake .#<selected profile> -b backup
```
They do not exist until `sh init.sh` is run; their contents depend on the host/profile selected there.

## Architecture

### Flake Outputs

- **nixosConfigurations**: `msiLaptop`, `desktop`, `wsl`
- **homeConfigurations**: `pastel@msiLaptop`, `pastel@desktop`, `material`, `wsl`

### System Config (`hosts/`)

- `hosts/shared/configuration.nix` — shared base: locale (ja_JP), fcitx5-mozc IME, PipeWire audio, Tailscale, xremap (CapsLock→Ctrl), Hyprland+UWSM, GDM
- `hosts/msiLaptop/` — Intel GPU drivers, KDE Connect, i915 kernel params
- `hosts/desktop/` — NVIDIA open drivers, Lanzaboote secure boot, nvidia-container-toolkit, Samba
- `hosts/wsl/` — minimal WSL config

`hardware-configuration.nix` files are auto-generated by `nixos-generate-config` — don't edit manually.

### Home Manager (`pastel/`, `material/`, `wsl/`)

There is no shared `home.nix`. Each profile has its own root module — `pastel/pastel.nix`, `material/material.nix`, `wsl/wsl.nix` — imported directly by `flake.nix`. Profile-specific host deltas live in `pastel/hosts/<host>.nix`.

> **Do not modify `material/` unless explicitly asked.** It is not the actively-used profile; active desktop work happens in **`pastel/`**, so make changes there by default. Only touch `material/` when the user names it directly.

- **pastel** — active profile; `pastel/pastel.nix` imports `pastel/programs/*.nix` and `pastel/tools.nix`; per-host deltas in `pastel/hosts/`
  - `pastel/programs/my-shell.nix` — the bar (github:minearchive/shell); niri spawns it, Matugen writes `~/.config/my_shell/theme.toml`
  - `pastel/programs/matugen/` — MD3 colour generation config
  - `pastel/tools.nix` — general tools and services
- **material** — deprecated reference profile; root is `material/material.nix`
  - `material/development.nix` — dev tools: gcc, go, python312, nodejs_22, bun, deno, jdk, nixd, devenv, direnv, IntelliJ IDEA
  - `material/quickshell.nix` — copies QML files to `~/.local/share/qs-bar/`, triggers Matugen, launches QuickShell via activation hook
  - `material/programs/hyprland.nix` — full Hyprland config (keybinds, animations, startup, gestures)
  - `material/programs/` — per-app configs (kitty, neovim, firefox, zen, git, mako, wlogout, spotify, etc.)
  - `material/templates.nix` — Nix dev templates (large file)
- **wsl** — fish shell + claude-code, no Wayland

### QuickShell / Bar UI

**Active:** `pastel/programs/my-shell.nix` pulls the bar from the `my-shell` flake input (github:minearchive/shell); its QML lives outside this repository. Theme colours arrive via Matugen → `~/.config/my_shell/theme.toml`.

**Deprecated:** `material/quickshell/` holds QML copied to `~/.local/share/qs-bar/` by `material/quickshell.nix`. Changes there require re-running the activation hook (or `home-manager switch`) and restarting quickshell. Structure: `shell.qml` (root), `topbar/` (clock, media player, hardware monitors, notifications, workspace switcher), `theme/` (`Colors.qml`, `Fonts.qml`, populated by Matugen), `appLauncher/`, `popout/`, `service/`, `component/`, `shader/`.

### Theming

Matugen generates Material Design 3 colors from the current wallpaper. Colors flow into QuickShell QML theme files and Qt5ct config. The wallpaper script (`~/.config/hypr/script/wallpaper_change.sh`) triggers Matugen on wallpaper change.

## Notes (`notes/`)

Records of issues encountered and how they were resolved. Each file covers one topic and is written to be useful for AI agents — including what was tried, why it failed, and what the final fix was. Check here before investigating a recurring problem.
